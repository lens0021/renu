# renu

목소리가 지금 어느 음인지 실시간으로 보여주고, 음역대를 기록해 두는 웹앱입니다.
모바일 브라우저에서 바로 쓰거나 PWA 로 설치할 수 있습니다.

## 하는 일

- **절대음감 표시** — 지금 내는 소리를 음이름(C♯4 같은)과 센트 편차, 주파수로 보여줍니다.
- **시간축 히스토리** — 가로가 시간이고 새 값이 오른쪽에서 붙으며 왼쪽으로 흘러갑니다.
  최근 8 초 동안 음이 어떻게 움직였는지 보입니다.
- **사람 음역만** — C2 – C6 밖의 소리는 들려도 무시합니다. 조율할 악기를 고르거나
  어느 줄을 맞추는 중인지 보여주는 화면은 없습니다.
- **음역대 저장** — 편집 모드에서 이름과 최저·최고음을 잡아 두면 계속 남습니다.
  브라우저의 localStorage 에 저장되고 기기 밖으로 나가지 않습니다.
- **기준 음역대** — 저장한 음역대 중 하나를 기준으로 삼으면, 그 밖의 소리는 소음으로 보고
  버립니다. 자기 음역을 지정해 두면 주변 소리에 덜 흔들립니다.
- **남성·여성 일반 음역대** — 성종별 범위(남성 E2 – C5, 여성 F3 – C6)를 배경에 흐리게
  깔아 둘 수 있습니다.
- **완전한 검정 테마** — 배경이 `#000` 입니다. OLED 화면은 검은 픽셀을 끄기 때문에
  그만큼 배터리를 덜 씁니다.
- **화면 유지** — Screen Wake Lock 으로 켜 둔 동안 화면이 꺼지지 않습니다.
  탭을 벗어나면 마이크 처리를 멈추고 잠금도 놓습니다.

## 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 마이크 켜기·끄기 | 왼쪽 위 `듣는 중` 버튼 |
| 음역대 추가·편집 | 오른쪽 위 `편집` |
| 노래로 음역 잡기 | 편집 시트의 `노래해서 잡기` 를 켠 채로 최저·최고음을 냄 |
| 지금 내는 음을 넣기 | 편집 시트의 `지금 음` |
| 기준 음역대 지정 | 편집 시트의 `이 음역대를 기준으로 삼고, 벗어난 소리는 무시` |
| `현재` 초기화 | 아래 범례에서 `현재` 칩을 누름 |

`현재` 는 앱을 켜 둔 동안 실제로 낸 음역이고 저장되지 않습니다.
계속 남길 음역대는 편집에서 이름을 붙여 저장하세요.

## 음 검출

[Tuner](https://github.com/moekadu/tuner) 의 접근을 참고했습니다. 자기상관으로 기본
주파수를 잡고, 보간으로 정밀도를 올리고, 아웃라이어를 걸러 스무딩합니다. 구현은 새로
썼고 웹 환경에 맞춰 이렇게 바꿨습니다.

1. 목표 대역이 사람 음역뿐이라 저역통과 후 1/4 로 데시메이션해 NSDF(McLeod) 를 돌립니다.
   연산량이 1/16 로 줄어 모바일 배터리에 유리합니다.
2. 데시메이션한 격자는 고음에서 한 주기가 열 몇 샘플밖에 안 되므로, 피크 비교를 반드시
   포물선 보간값으로 합니다. 원시값으로 비교하면 격자에 우연히 잘 맞은 옥타브 아래
   피크가 이기면서 옥타브 오류가 납니다.
3. 원본 샘플레이트에서 주기의 정수배 `m·T` 근처를 정규화 상호상관으로 다시 찾습니다.
   같은 절대오차가 `m` 배로 희석되므로 상대 정밀도가 그만큼 좋아집니다. `m` 은 탐색창이
   이웃 주기를 덮지 않는 선에서 회차마다 키웁니다.
4. 검출 대역은 3 kHz 까지 열어 두고, 잡은 뒤에 사람 음역 밖을 버립니다. 대역을 좁게
   잡으면 고음의 정수분의 1 을 사람 음역 안의 음으로 착각합니다.

합성 신호 기준으로 깨끗한 음은 오차 0.00 센트, 잡음을 섞어도 표준편차 0.12 센트 아래,
하드 클리핑에도 0.05 센트 안쪽입니다.

## 실행

빌드 단계가 없습니다. 정적 파일을 그대로 띄우면 됩니다.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

마이크와 Wake Lock, 서비스워커는 보안 컨텍스트를 요구합니다. `localhost` 이거나
HTTPS 여야 합니다.

## 배포

`main` 에 push 하면 `.github/workflows/pages.yml` 이 저장소 전체를 GitHub Pages 로
올립니다. 저장소 설정에서 **Settings → Pages → Source** 를 `GitHub Actions` 로 한 번
바꿔 주세요. 모든 경로가 상대 경로라서 프로젝트 페이지(`/<repo>/`) 아래에서도 동작합니다.
